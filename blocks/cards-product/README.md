# cards-product

Custom **cards** block. Purpose: Product cards linking to product pages, with an optional wide promo card.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: image | name, text, link; a text-first row (body | image) is the wide promo card.

## Supported variations

No variations.
