# carousel-hotspot

Custom **carousel** block. Purpose: Image slider whose photos carry product hotspots with popovers.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: image | hotspot cells starting with "x, y" percent position then heading, text, link; a cell without position is the caption.

## Supported variations

No variations.
