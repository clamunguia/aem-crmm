# carousel-media

Custom **carousel** block. Purpose: Slider of photo or video tiles with captions.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per tile: image and/or video link | caption.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |
| Alt | `alt` |
| Alt 2 | `alt-2` |
