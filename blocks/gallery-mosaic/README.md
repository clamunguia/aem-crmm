# gallery-mosaic

Custom **custom** block. Purpose: Edge-to-edge photo mosaic, or a colour swatch picker / palette browser.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: mosaic: cells with image (+ optional link); swatch options: one row per colour: swatch image | name | family (optional) | link (optional).

## Supported variations

| Variation | Option class |
| --- | --- |
| Swatches | `swatches` |
| Cyan Light Green Grey Orange Yellow | `cyan-light-green-grey-orange-yellow` |
