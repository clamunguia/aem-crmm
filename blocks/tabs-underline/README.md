# tabs-underline

Custom **tabs** block. Purpose: Tab labels with underline on the active one, or category tab navigation.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per tab: label | panel content or /fragments/ link; link-only labels with no panels render as navigation.

## Supported variations

| Variation | Option class |
| --- | --- |
| Alt | `alt` |
| Alt 2 | `alt-2` |
| Alt 3 | `alt-3` |
