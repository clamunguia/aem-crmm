# cards-article

Custom **cards** block. Purpose: Article teaser and icon link cards.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: image or icon | title, tag, link.

## Supported variations

| Variation | Option class |
| --- | --- |
| Icon | `icon` |
| Featured | `featured` |
| Light | `light` |
| Icon 2 | `icon-2` |
| Buttons | `buttons` |
| Icon Alt | `icon-alt` |
