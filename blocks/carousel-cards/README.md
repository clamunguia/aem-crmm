# carousel-cards

Custom **carousel** block. Purpose: Heading and intro beside a slider of link cards.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: leading row(s) without image: intro heading, text, link; then one row per card: image | title, text, link.
